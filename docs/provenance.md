# Example provenance and licensing

All tiny fixtures and loopback capture artifacts in this source archive were generated by the original included builders/harness. They contain one-host controlled trace data, not user production traffic. Instrumentation timestamp offsets and the separately described corruption control are deliberate. The protobuf uses the official OpenTelemetry encoder; its JSON view converts protobuf byte IDs to OTLP hex IDs and uses numeric enums.

The raw issue fixture reviewed during project selection is not included. Links to external issues and prior art do not grant licenses to redistribute their attachments. Jaeger's upstream binary and source are not included; the comparison tool requires the operator to supply an official, checksum-verified binary. Generated example outputs are covered by this project's MIT license.
